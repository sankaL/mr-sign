## Page Hero / Banner

**Layout:** Slim page header strip. Clean and minimal so the focus goes immediately to the form below. Light background. No large photo needed here -- keep the page fast and form-forward.

**Headline:** Request a Free Quote

**Subheadline:** Fill out the form below and our team will get back to you by phone or email -- usually within one business day. No obligation, no account required.

**Note for designer:** Include a small, reassuring icon beside the subheadline -- a checkmark circle or a calendar icon to reinforce the "quick response" message.

---

## Trust Strip (above the form)

**Layout:** A horizontal row of 3 short trust statements below the header and above the form. Small icons beside each one. Light background or subtle border to visually separate this from the form.

**Trust Item 1**
- **Icon:** Clock or fast-forward icon
- **Text:** We typically respond within one business day.

**Trust Item 2**
- **Icon:** Lock or shield icon
- **Text:** Your information is kept private and never shared.

**Trust Item 3**
- **Icon:** Checkmark or no-credit-card icon
- **Text:** No payment required to request a quote.

---

## Quote Request Form

**Layout:** A clean, single-column form with clearly labelled sections. Group related fields together. Each section has a subtle section header. Use generous spacing so the form does not feel crowded. On desktop, some field pairs (like First Name / Last Name) can sit side by side. On mobile, all fields stack vertically.

---

### Section 1: Your Contact Information

**Section Label:** About You

| Field | Type | Required | Placeholder / Help Text |
|---|---|---|---|
| First Name | Text input | Yes | Your first name |
| Last Name | Text input | Yes | Your last name |
| Email Address | Email input | Yes | we will send your quote confirmation here |
| Phone Number | Phone input | Yes | Best number to reach you |
| Company Name | Text input | No | Optional -- leave blank if not applicable |
| Preferred Contact Method | Radio buttons | Yes | Options: Phone, Email, Either |

---

### Section 2: Your Project Details

**Section Label:** Tell Us About Your Project

| Field | Type | Required | Placeholder / Help Text |
|---|---|---|---|
| Service Category | Dropdown | Yes | Options: Signs, Printing, Design |
| Service | Dropdown (dynamic, based on category selected) | Yes | Options update based on category |
| Quantity | Number input | No | How many units do you need? (leave blank if unsure) |
| Size or Dimensions | Text input | No | e.g. 24" x 36", full-page, etc. (leave blank if unsure) |
| Material Preference | Text input | No | e.g. vinyl, coroplast, glossy paper (leave blank if unsure) |
| Desired Completion Date | Date picker | No | When do you need this by? |
| Project Details and Notes | Textarea | Yes | Tell us more about your project. The more detail you include, the more accurate your quote will be. |

---

### Section 3: Confirmation

**Section Label:** Almost Done

**Checkbox (required):**
I agree to be contacted by Mr. Sign and Print regarding my quote request. I understand that no payment is collected at this stage.

**Note below checkbox (small text):**
After you submit, you will receive a quote request code by email. Keep this code handy -- you can reference it when you follow up with us.

---

### Submit Button

**Button Label:** Submit My Quote Request

**Button style:** Large, full-width on mobile, prominent on desktop. Use the brand's primary CTA colour.
