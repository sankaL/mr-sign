---

## Page Hero / Banner

**Layout:** Slim, clean page header. Light background with the page title and a short, welcoming subheadline. This page does not need a large hero image -- it should feel approachable and simple.

**Headline:** Get in Touch

**Subheadline:** Have a question about a product or service? Want to check on a quote? Just want to say hello? We would love to hear from you.

---

## Page Layout Overview

**Layout:** On desktop, use a two-column layout below the header.
- **Left column (about 55% width):** Contact form
- **Right column (about 45% width):** Contact details block, business info, and map

On mobile, stack everything vertically: contact details first (phone number prominently for tap-to-call), then the form below.

---

## Left Column: Contact Form

**Section Label:** Send Us a Message

**Form Layout Notes:** Single column of fields, clearly labelled, generous spacing. A clean, simple form that feels easy to complete.

| Field | Type | Required | Placeholder / Help Text |
|---|---|---|---|
| First Name | Text input | Yes | Your first name |
| Last Name | Text input | Yes | Your last name |
| Email Address | Email input | Yes | We will reply to this address |
| Phone Number | Phone input | No | Optional -- in case you prefer a call back |
| Reason for Contact | Dropdown | Yes | Options listed below |
| Message | Textarea | Yes | How can we help you? |

**Reason for Contact Dropdown Options:**
- General Question
- Question About a Service
- Quote Request
- Order Inquiry
- Follow Up on an Existing Request
- Other

**Note below the Reason for Contact field (small text):**
If you are ready to request a formal quote, you can use our dedicated Quote Request page for a faster response.

**Submit Button Label:** Send My Message

**Below the submit button (small text):**
We typically respond within one business day.

## Additional Notes for the Page

**Mobile note for designer:** On mobile, display the phone numbers near the top of the page with a large, clearly tappable "Call Now" button. This is the fastest conversion action for mobile users. The form can sit below.

**Helpful bottom strip (optional):**
Below the form and contact details, add a small strip with a link to the quote page, since some people who visit the Contact page may actually be ready to request a quote.

**Strip Copy:** Not just reaching out -- ready to get started?

**Strip Links:**
- Request a Quote (links to /request-quote)
