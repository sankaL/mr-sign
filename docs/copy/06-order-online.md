## Page Hero / Banner

**Layout:** Slim, clean page header strip. Minimal design -- this page is about completing an action, so keep the focus on the form. Use a light background and a concise, reassuring headline.

**Headline:** Submit Your Order Request Online

**Subheadline:** Already know what you need? Fill out the form below and we will reach out to confirm your order details and get things moving. No payment is collected online.

**Note for designer:** Add a small process summary beside or below the subheadline -- something like "Submit your request, we confirm, we produce, you pick up." Three or four steps shown as a compact horizontal icon row to set expectations.

---

## Process Steps Strip (above the form)

**Layout:** Horizontal strip with three or four compact steps. Each step has a number, a small icon, and a short label. Clean, minimal design.

**Step 1**
- **Icon:** Clipboard or form icon
- **Label:** Fill Out the Form

**Step 2**
- **Icon:** Phone or speech bubble icon
- **Label:** We Confirm Your Order

**Step 3**
- **Icon:** Wrench, printer, or gear icon
- **Label:** We Get to Work

**Step 4**
- **Icon:** Package or checkmark icon
- **Label:** Pick Up or Delivery

## Order Request Form

**Layout:** A clean, single-column form with clearly labelled sections. Group related fields. Each section has a subtle section header. On desktop, field pairs can sit side by side where it makes sense. On mobile, all fields stack vertically. Generous spacing throughout.

---

### Section 1: Your Contact Information

**Section Label:** Your Details

| Field | Type | Required | Placeholder / Help Text |
|---|---|---|---|
| First Name | Text input | Yes | Your first name |
| Last Name | Text input | Yes | Your last name |
| Email Address | Email input | Yes | We will send your order confirmation here |
| Phone Number | Phone input | Yes | Best number to reach you |
| Company Name | Text input | No | Optional |
| Preferred Contact Method | Radio buttons | Yes | Options: Phone, Email, Either |

---

### Section 2: Your Order Details

**Section Label:** What Are You Ordering?

| Field | Type | Required | Placeholder / Help Text |
|---|---|---|---|
| Service Category | Dropdown | Yes | Options: Signs, Printing, Design |
| Service | Dropdown (dynamic, updates based on category) | Yes | Options update based on category |
| Quantity | Number input | Yes | How many do you need? |
| Size or Dimensions | Text input | No | e.g. 24" x 36", 8.5" x 11", etc. |
| Material or Finish | Text input | No | e.g. glossy paper, vinyl, coroplast (leave blank if unsure) |
| Colour Preferences | Text input | No | e.g. match our existing branding, red and white, full colour |
| Do you have artwork ready? | Radio buttons | Yes | Options: Yes -- I will email my files, No -- I need design help, I have a rough idea |
| Desired Completion Date | Date picker | No | When do you need this by? |
| Order Notes and Details | Textarea | Yes | Tell us everything you can about your order. Include any specific requirements, file details, or anything we should know. |

---

### Help Text Beneath "Do you have artwork ready?" Field

**Note (shown below the field, small text):**
If you have files ready, please email them to order@mrsignandprint.net after submitting this form. Include your order code in the subject line so we can match your files to your request.

If you need design help, select that option and we will include design time in our quote.

**Note below checkbox (small text):**
After you submit, you will receive an order request code by email. Keep this code handy -- you can use it when following up with us.
