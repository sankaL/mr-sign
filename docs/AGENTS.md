# Docs Guidance

- Keep documentation files under 1000 lines when possible
- If content exceeds 1000 lines, create a numbered file (e.g., `[filename]-002.md`). You can allow up to 1200 lines if splitting mid-topic would hurt readability. Never split the same topic across multiple files.

---

## Writing Guidelines

When writing documents:

1. Remove fluff as much as possible and keep things concise without compromising the actual details that's necessary
2. Never use em-dashes
3. Never use emojis

When working on anything visual, like a one-pager, PowerPoint, or video, for example, in reMotion:

- Never use emojis
- Try to minimize using gradient colors
- Ask me if I prefer a specific theme before creating the document
